Local-first by design

Your transcript is not Jelluvi’s business.

Export rendering runs inside the extension. There is no Jelluvi account, export server, analytics SDK, remote renderer, or hosted transcript store. Conversation content is stored only when you explicitly save it to the Local Library in your browser.

Install today

Build and load the extension in a few minutes.

  1. Clone the repository and run pnpm install --frozen-lockfile.
  2. Run pnpm build.
  3. Open your browser’s extensions page and load the generated dist folder.

FAQ

Before you install.

Does Jelluvi upload chats?

No. Export rendering runs locally inside the extension.

Why is there no Scan button?

Export, copy, preview, and library save actions prepare the current chat automatically. Refresh remains available after preparation.

Does it export my full account history?

No. Jelluvi exports supported chat tabs that you explicitly choose.
